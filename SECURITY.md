# Security

## Scope

This repository is being prepared for a testnet-only hackathon demonstration.
There is no production security or funds-safety guarantee. Shared judge accounts
are disposable demonstration identities and do not establish real-athlete consent.

Never include secrets, private keys, wallet seeds, passwords, authentication
exports, signed private payloads or real participant contact data in an issue,
pull request or commit. Real historical results can remain linkable after names
are changed; public fixtures must be synthetic.

## Reporting

Keep suspected vulnerabilities confidential. Use GitHub's **Report a vulnerability**
action in this repository's Security tab when it is available. If the action is
unavailable, contact the repository owner through an existing private channel;
do not publish exploit details in a public issue. No response-time commitment is
implied. Private reporting availability will be verified before public release.

## Review status

The reviewed local source passed its focused dependency regressions and a registry
audit reporting zero known advisories on 4 October 2026. Those checks cover the
specific tested source, including separately tested local dependency patches.
They do not certify this future source import, media, configuration or deployment.
The exact imported commit must receive its own checks before public release.
